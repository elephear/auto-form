测试站点 A（layui 风格）：隐藏 select + 皮肤单选/复选 + 注册两步式流程

① 注册账号 ② 填写网申信息 ③ 登录（验证已保存信息）

使用「自动表单填写助手」测试

按下 Ctrl + / 打开填写面板 → 选择/拖入 test/resume.docx 或 resume.txt → 点击「开始智能填写」。
注册页会自动生成符合规则的账号与密码并保存；网申页会把简历内容映射到各字段； 登录页可直接使用已保存的账号密码。
  1. 先在 注册账号 页完成注册（扩展会自动填写，然后点击页面上的「注册」按钮）。
  2. 进入 填写网申信息，再次使用 Ctrl + / 填写简历信息并提交。
  3. 退出后到 登录 页，用 Ctrl + / 一键填入已保存的账号密码。
