按 Ctrl + / 打开填写面板 → 导入 test/resume.docx 或 resume.txt → 点击「开始智能填写」。
本站点使用 表格布局（th + td）、原生可见下拉，密码字段带 pattern 正则； 注册页需要填写验证码（测试验证码 123456）并勾选用户协议。
  1. 进入 注册账号：扩展会生成符合正则的密码、填写邮箱与验证码并勾选协议，然后点击页面「注册」按钮。
  2. 进入 填写网申信息：再次按 Ctrl + / 自动填写完整表格并提交。
